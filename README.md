## Featured project

### [Arabic Verb WSD with Context–Gloss Pairs](https://github.com/AsmaML/arabic-wsd-context-gloss)

A research repository presenting datasets and experiments from my doctoral work on Arabic verb sense disambiguation.

- 51,161 revised and labeled Arabic context–gloss pairs
- Data-quality analysis and documented dataset lineage
- Fine-tuning workflows for AraBERT, CAMeLBERT, ARBERTv2 and Arabic ALBERT
- Logistic-regression stacking of complementary Arabic language models
- Best ensemble result: **82.11% accuracy and 82.97% F1-score**
